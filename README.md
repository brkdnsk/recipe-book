# 🍳 Tarif Defterim (Recipe App)

Bu proje, modern bir web arayüzü, mobil uygulama ve güçlü bir Java Spring Boot backend altyapısından oluşan, tam kapsamlı bir **Monorepo Tarif Yönetim Sistemi**dir. Kullanıcıların lezzetli tarifler eklemesini, düzenlemesini, silmesini, kategorize etmesini ve aramasını sağlar.

---

## 🚀 Kullanılan Teknolojiler

### Backend
* **Java 17**
* **Spring Boot** (RESTful API, Spring Data JPA)
* **PostgreSQL** (Veritabanı)
* **Lombok**

### Web Frontend (`recipe-frontend`)
* **React** (Vite)
* **Bootstrap 5** & **Bootstrap Icons**
* **Axios** (API Entegrasyonu)
* Özel Akıcı CSS Animasyonları

### Mobil Frontend (`recipe-mobile`)
* **React Native** (Expo)
* **Axios**

---

## ⚙️ Temel Özellikler

* **Tam Kapsamlı CRUD İşlemleri:** Tarif ekleme, listeleme, güncelleme (düzenleme) ve silme.
* **Anlık Arama ve Filtreleme:** Tarif adı veya açıklamalarında hızlı arama yapabilme ve kategorilere göre filtreleme.
* **Modern ve Responsive Tasarım:** Web tarafında Bootstrap 5 ile şık kart yapısı, mobil tarafında ise Expo uyumlu akıcı arayüz.
* **Çoklu Platform Desteği:** Tek bir backend API'sine bağlanan hem modern Web paneli hem de Mobil uygulama.
